# Contributing

Thanks for considering contributing! A few guidelines to keep things smooth:

- Fork the repo and create a branch named `feature/<short-desc>` or `fix/<short-desc>`.
- Write tests for new behavior and ensure existing tests pass (`./mvnw test`).
- Keep commits focused and write clear commit messages.
- Open a Pull Request describing the change and link to any related issues.

Code style: follow existing project conventions and prefer simple, readable code.

Once merged, the CI will run the build and tests automatically on `main` and PRs.
